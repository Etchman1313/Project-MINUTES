---

Mission

Build the first interactive archive document.

Do NOT build a card.

Do NOT build a modal.

Do NOT build an accordion.

Build an artifact.

---

Concept

The visitor encounters an official archive folder.

The folder rests on a virtual desk.

It appears tangible.

Weathered.

Used.

Handled.

Important.

---

Appearance

Heavy paper stock.

Brass fastener.

Stamped.

Folded corner.

Handwritten archive number.

Coffee ring.

Slight warp.

Visible fibers.

Subtle imperfections.

Nothing decorative.

Everything functional.

---

Interaction

Initially closed.

Hover creates almost no movement.

A slight shift.

Nothing theatrical.

Click opens the folder.

The top cover rotates upward.

A document slowly slides into view.

The paper settles naturally.

No bounce.

No overshoot.

No spring animation.

RECORD GROUP 12

MINUTE 287

ARTICLE VII

DECLASSIFIED

display placeholder body text using semantic HTML that will later be replaced with manuscript excerpts.

---

Motion

Movement should resemble:

opening a physical folder

sliding paper

gravity

weight

friction

dust

Never resemble an app.

---

Audio Hooks

Do not add audio.

But provide JavaScript events where later we can trigger:

paper

folder

stamp

drawer

---

Accessibility

Folder must be fully keyboard accessible.

Enter opens.

Escape closes.

ARIA expanded states.

Logical focus order.

---

Performance

CSS transforms only.

No layout thrashing.

No external libraries.

---

Goal

When someone opens the folder,

they should instinctively lean toward the monitor.

Return updated HTML, CSS and JavaScript.
