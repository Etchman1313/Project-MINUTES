# Project MINUTES
## AI Engineering Rules

Version 1.0

---

# Mission

The purpose of this project is NOT to create a website.

The purpose is to create an immersive narrative experience that feels like an official archive documenting an alternate American history.

Every line of code must support immersion.

If a feature does not increase immersion, remove it.

---

# Philosophy

Less is more.

Silence is a design element.

Motion has meaning.

Typography carries emotion.

Objects tell stories.

The visitor is intelligent.

Never explain what can be discovered.

# HTML Rules

Semantic HTML only.

Every section must have a purpose.

No meaningless wrapper divs.

Accessibility is mandatory.

Use ARIA only when appropriate.

---

# CSS Rules

Variables first.

No magic numbers.

No inline styles.

No !important.

Prefer Grid over nested Flexbox where appropriate.

Every animation must be intentional.

Transitions should feel cinematic.

---

# JavaScript Rules

Modular.

No global variables.

No frameworks.

Every function documented.

No unnecessary dependencies.

Animations should use requestAnimationFrame where appropriate.

---

# Performance

Target Lighthouse score above 95.

Lazy load assets.

Optimize images.

Minimize layout shift.

Prefer CSS over JavaScript animations.

---

# Tone

Never look like marketing.

Never look like WordPress.

Never look like a template.

The visitor should forget they are browsing a website.

---

# Decision Rule

If two solutions are equally good...

Choose the simpler one.

If one solution is more cinematic...

Choose the cinematic one.

If something exists only because it looks cool...

Delete it.
