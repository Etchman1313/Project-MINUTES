# PROJECT MINUTES
## CREATIVE STATE

**Status:** Living Document  
**Revision:** 1.0

---

# Current Date

July 2026

---

# Creative Temperature

High.

The project has transitioned from a website into an immersive narrative experience.

The visual language has become coherent, and the core creative direction is now stable.

---

# Current Obsession

Cabinet Zero.

The project is no longer about pages.

It is about creating a believable physical place where history is preserved.

Everything else will grow naturally from this room.

---

# Biggest Breakthrough

The realization that the visitor is **the first civilian granted access after declassification**.

This transformed the authentication sequence from a loading animation into a narrative event.

It also redefined every interaction that follows.

---

# Biggest Course Correction

We intentionally moved away from revealing story content.

Originally the archive risked becoming a companion encyclopedia.

The project now focuses on implication instead of explanation.

Artifacts exist to create curiosity, never to resolve it.

---

# Current North Star

> The website creates questions.

> The novel creates understanding.

Every design decision must reinforce this principle.

---

# Emotional Goal

Visitors should feel:

- Trusted
- Curious
- Reflective
- Responsible

They should never feel marketed to.

---

# Visual Goal

The experience should resemble a National Archives conservation laboratory.

Not a museum.

Not a bunker.

Not a dashboard.

A real place where history is carefully preserved.

---

# Production Focus

The next major effort is the Vision Book.

The Vision Book becomes the visual source of truth for every future implementation.

Engineering follows the Vision Book.

It does not invent it.

---

# Things We Must Protect

- Never spoil the novel.
- Never over-explain.
- Never add features because they are technically impressive.
- Every interaction must have narrative purpose.
- Every artifact must reward close inspection.

---

# Open Questions

- What is the final visual composition of Cabinet Zero?
- How should ambient sound support the experience?
- How many hero artifacts should exist at launch?
- Where does the transition from archive to purchase occur?

These questions remain intentionally unresolved.

---

# Reminder

We are not building a website.

We are building the first five minutes of a relationship between a reader and *The Uncivil War*.

Everything should earn that relationship.
